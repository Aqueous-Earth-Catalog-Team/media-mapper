# Shark Attack! 🦈

This is an interactive map that locates movies that feature shark attacks. To suggest an item to be added, please fill out <a href="https://docs.google.com/forms/d/1jM1nK4YeuI016yaeT1xYzVbffGNf_swzXf5NrrvD6UI/edit"> this form</a>.

## Made with Media Mapper

The Media Mapper is an open source framework intended to be used as a starting point for building a web application geared towards exploring Media throughout time and space.

The project was dreamt up by <a href="https://ennurijo.com"> Ennuri Jo </a> as a way to explore the relationship between media and water. Funding for this project was provided by the <a href="https://www.asc.upenn.edu/research/centers/center-for-advanced-research-in-global-communication"> Center for Advanced Research in Global Communication </a> at the University of Pennsylvania. The framework was developed by Ben Tyler and <a href="https://lostcreekdesigns.co"> Lost Creek Designs </a>.

Please see the <a href="https://github.com/Aqueous-Earth-Catalog-Team/media-mapper"> GitHub repository </a> for more information about how you can get started with the project!
